Guía de Uso: Coordinador

  1. Registro de Cuenta

    2. Como coordinador, el primer paso es crearte una cuenta en la página de registrar.

  2. Inicio de Sesión

    3. Una vez creada tu cuenta, inicia sesión con tus nuevas credenciales login.

  3. Visualización del Presupuesto en el Portal

    4. Después de que el Contador te asigne tus Centros de Costos, dirígete a la página de portal para ver el presupuesto de tus centros.

  4. Funcionalidades de la Tabla

    5. La tabla de presupuesto te permite:

    • Aplicar filtros para visualizar información específica.
    • Guardar cambios si realizas alguna modificación.
    • Exportar a Excel para trabajar con los datos fuera de la aplicación.
  5. Creación de Comentarios

    6. Puedes añadir comentarios y solicitudes sobre el presupuesto. Estos serán revisados y resueltos posteriormente por el Contador.

  6. Visualización del Dashboard

    7. Finalmente, haz clic en el botón dashboard para ver un resumen visual de la información de tus centros. El dashboard es interactivo: puedes mostrar u ocultar las cuentas que desees para un mejor análisis.
